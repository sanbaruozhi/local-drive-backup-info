隐私政策 / Privacy Policy

适用于 Local Drive Incremental Backup。更新日期：2026-09-12。

用途与使用范围

本工具在所有者的 Mac 上运行，仅用于将其选定的本地文件夹备份至本人授权的 Google Drive 目录，并比较和核验文件内容。

访问的数据

工具访问执行备份所需的文件内容、文件名、文件大小、修改时间、内容校验值、文件与目录标识，以及用于确认所连接账号的基本资料。为使用既有云端备份目录，Google 授权范围包含 Google Drive 文件访问权限；实际备份目标由本地配置指定。

存储与传输

备份文件保存在所有者的 Mac 和本人 Google Drive 账号中。授权凭据、运行状态及备份日志保存在所有者的 Mac 上，凭据文件限制为该本地用户访问。工具通过 HTTPS 与 Google Drive API 通信。

数据使用与共享

工具仅为备份、恢复所需的文件访问及完整性核验使用 Google 用户数据，不将其出售，不用于广告、数据交易或模型训练，也不上传至本说明网站或 GitHub 项目。本工具对 Google API 所获信息的使用与转移遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

撤销授权与删除

所有者可停止本地备份任务，并在 Google 账号第三方连接设置中撤销授权。撤销授权将停止后续访问，已存在的本地文件和云端备份由所有者自行保留或删除。本工具的日常增量备份不会自动删除云端额外文件。

本说明网站

本网站仅包含公开的用途与隐私说明，没有备份内容、登录表单或应用自行添加的访问统计。网站由 GitHub Pages 托管；托管平台对网站访问请求的处理适用 GitHub 隐私声明。
